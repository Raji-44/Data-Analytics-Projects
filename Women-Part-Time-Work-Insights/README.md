# 📊 Women Part-Time Work Insights Dashboard

## 📌 Project Overview  
This project analyzes participation trends, income patterns, and working conditions of women engaged in part-time jobs.  
The dataset is based on survey responses collected from the local community and analyzed using Excel and Power BI.

---

## 👩‍💼 Key Highlights  
- Analyzed data from **150 women respondents**  
- Studied participation across multiple part-time job categories  
- Evaluated income distribution based on job type, age, and education  
- Identified working hour patterns and preferences  
- Built interactive Power BI dashboard for visualization  

---

## 🛠 Tools Used  
- Microsoft Excel  
- Power BI  
- Data Cleaning  
- Data Visualization  

---

## 📊 Key Insights  
- Majority of women prefer flexible part-time jobs  
- Income varies significantly based on job type and working hours  
- Education level influences job category selection  
- Age group impacts participation in certain job types  
- **72.87% respondents are willing to refer job opportunities to others**
