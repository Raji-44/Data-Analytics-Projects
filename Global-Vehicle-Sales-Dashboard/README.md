# 📊 Global Vehicle Sales & Performance Dashboard

## 📌 Project Overview  
This project analyzes multi-year vehicle sales performance using Excel dashboards.  
It tracks revenue, profit, and product category trends across different countries from 2023 to 2025.

---

## 🚗 Key Highlights  
- Analyzed **$9.8M profit data** across global markets  
- Studied performance across **19 countries, 92 customers, and 2,823 products**  
- Evaluated year-over-year sales trends (2023–2025)  
- Segmented performance by product categories  
- Built interactive Excel dashboard using pivot tables and charts  

---

## 🛠 Tools Used  
- Microsoft Excel  
- Pivot Tables  
- Charts & Graphs  
- Data Cleaning  
- Data Analysis  

---

## 📊 Key Insights  
- Classic Cars and Motorcycles are top-performing categories  
- Sales show consistent growth in selected regions  
- Certain countries contribute majority of total revenue  
- Seasonal trends impact overall vehicle sales performance  
- Customer segmentation helps identify high-value buyers
