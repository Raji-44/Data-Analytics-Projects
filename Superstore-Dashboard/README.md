# 📊 Superstore Sales Dashboard

## 📌 Project Overview
This project analyzes sales, profit, and order data from a Superstore dataset using Power BI.  
It provides insights into business performance across regions, categories, and customer segments.

Key highlights:
- Analyzed 9,994 orders with $2.30M total sales
- Built interactive dashboard with segment-wise analysis
- Identified top-performing products and sub-categories
- Evaluated regional profitability across the United States

## 🛠 Tools Used
- Power BI  
- Power Query  
- Data Cleaning & Transformation  
- Data Visualization  

## 📊 Key Insights
- Total Sales: $2.30M  
- Total Orders: 9,994  
- Strong performance in specific regions and categories  
- Profit variation across product sub-categories  
- Underperforming segments identified for improvement
