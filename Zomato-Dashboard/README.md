# 📊 Zomato Global Market Presence Dashboard

## 📌 Project Overview  
This project analyzes global cuisine demand and restaurant distribution across multiple countries using Power BI and Power Query.  
It provides insights into food trends, ratings, pricing, and cuisine popularity across different regions.

---

## 🌍 Key Highlights  
- Analyzed data from **9,551 restaurants across 16 countries**  
- Studied **1,826 cuisine types globally**  
- Identified top cuisines by country and region  
- Compared restaurant ratings across locations  
- Analyzed pricing patterns and food category trends  
- Built an interactive Power BI dashboard for business insights  

---

## 🛠 Tools Used  
- Power BI  
- Power Query  
- Data Cleaning & Transformation  
- Data Visualization  

---

## 📊 Key Insights  
- Certain cuisines dominate specific countries and regions  
- Significant variation in average ratings across locations  
- Price distribution differs heavily based on region and cuisine type  
- Some countries show higher diversity in food offerings than others  
- Premium pricing is strongly linked to restaurant ratings
